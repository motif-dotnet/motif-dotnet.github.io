Opinionated, AI-assisted tooling for building .NET apps, from first sketch onwards.

Motif.NET is a suite of tools and conventions for building .NET apps with a coding agent. Each one does one job well, and they work together through files in the app's repo, so a design you sketch can become a plan that a coding agent builds from.

Using them is optional: pick the ones you want, and none of them gets in your way by default. The tools run in the browser, with no server and no accounts.

Coming later

Ideas, written up but not built yet. Expect some to change, merge or drop out.

  • Motif CLI dotnet motif: sets up the motif/ folder in a repo, and runs gentle checks.
  • Glossary checks: flag words to avoid, terms still proposed, and sketch names with no glossary entry.
  • Glossary editor: browse and edit motif/glossary.md, growing out of Motif Glossary.
  • Agent review: a review prompt that checks a change against Motif's opinions on architecture, naming and style, and gives advice only.
